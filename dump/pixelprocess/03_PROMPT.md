## Canonical processing flow PIXEL-01

1. Background classifier → identify transparent pixels and border-connected magenta → source background mask without changing image colors. Use configurable color tolerance and four-neighbor background connectivity; preserve enclosed magenta. Weak border evidence must produce a warning rather than classify every magenta-like color as background.
2. Ownership detector → find eight-connected foreground components using that mask → blobs, sheet cells, and stable sprite ownership. Prefer explicit grid settings; otherwise infer cells only from clear empty lanes. Assign detached parts within known cells to their sprite. Preserve small components and empty slots; flag ambiguous grouping or components crossing cell boundaries for overrides. Produce provisional ownership using an explicit deterministic rule, record alternatives, and retain unresolved components without duplication or deletion. Avoid automatic dilation, hardcoded corner exclusions, and size-based deletion.
3. Sprite extractor → isolate each owner's source pixels with transparent padding → independent sprite crops and ownership masks. Retain source bounds, cell identity, and coordinate transforms. Mask other owners without clipping the sprite to an uncertain cell boundary.
4. Lattice fitter → score foreground color-edge periodicity for each sprite → one straight, uniform square lattice with pitch, X/Y phase, confidence, and competing candidates. Support fractional source-pixel pitch from the initial version, with configurable search bounds and refinement precision; exclude background and crop boundaries from evidence. Allow explicit pitch and phase overrides per sprite. Weak or ambiguous evidence uses a documented deterministic best-effort fit with warnings, candidate scores, and manual-input flags; other sprites continue. Never silently impose a sheet-wide pitch.
5. Reconstructor → sample the fitted lattice once → logical-resolution RGBA sprite and nearest-neighbor preview. Round each shared boundary once, cover the complete crop, and retain partial boundary cells. Decide foreground occupancy from owned, non-background coverage using an explicit threshold; measure coverage against the actual source-covered area of partial cells, record clipping, and never extrapolate samples beyond the source; select an existing source color from the dominant coarse color group, with deterministic ties. Keep occupancy separate from color confidence; uncertain color alone must not erase a cell.
6. Magenta cleaner → resolve residual background-supported cells and the selected cleanup policy → final sprite transparency. In default cleanup mode, reconstruction excludes classified background from color votes; this stage clears remaining cells classified as background by recorded source support, without a second independent flood or repeated sampling. Default cleanup removes classified background without crossing foreground barriers or deleting enclosed magenta. Provide explicit `all` and `skip` modes; `skip` preserves magenta colors in reconstruction and output, while the background mask remains available for detection and ownership. In `skip` mode, treat preserved background as output coverage and include its color samples only within the assigned sprite crop; do not turn the sheet background into a shared sprite owner. Keep ownership isolation active in every mode. Clear RGB when alpha is zero. Avoid repeated rim removal and halo expansion.
7. Sheet builder → place completed logical sprites in stable row/column order → rebuilt transparent spritesheet and placement metadata. Preserve empty slots, use a uniform canvas large enough for every sprite, center sprites by default, and expose anchor and padding settings. Keep logical pixel scale unchanged; differing sprite sizes must not trigger implicit resizing. Preserve individual sprite outputs. Debug/inspection views place processed sprites at their original source positions using recorded transforms; centering applies to final sheet placement only, with no logical resampling for export.
