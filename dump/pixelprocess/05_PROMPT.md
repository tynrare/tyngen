# Validation

Test and visually verify the implementation of prompts `01`–`04` before declaring completion. Use a small, reproducible fixture set with recorded expected outcomes and meaningful checks:

- Build, stage CLI/artifact contracts, metadata, and coordinate mappings.
- Fractional pitch, detached parts, enclosed magenta, partial cells, differing sprite sizes, and all cleanup modes.
- Best-effort results, visible uncertainty highlights, and manual stage/sprite corrections.
- Selective reruns, artifact reuse/invalidation, cancellation, partial failures, and restart recovery.
- Existing UI controls and generation/import conversion through export; inspect source-aligned comparisons and centered final spritesheets.

Review actual output images and rendered UI, including overlays under zoom/pan; automated checks alone do not establish visual quality. Keep tests focused on observable behavior. Report checks performed, failures resolved, and remaining limitations; do not claim unperformed checks passed.
